# VIANORA Website

Premium multi-page website for VIANORA Digital Marketing Agency.
Built with React, Vite, Tailwind CSS and React Router.

## Run on your computer

1. Install Node.js (LTS version) from https://nodejs.org
2. Open a terminal inside this folder
3. `npm install`   (downloads the tools, takes a minute)
4. `npm run dev`   (starts the site, open the link shown, usually http://localhost:5173)

## Other commands

- `npm run build`   creates the production version in the `dist` folder
- `npm run preview` previews that production version

## Where to edit content

Business details live in `src/data/siteConfig.js`.
Services, blog posts, portfolio, reviews and pricing data files are added in later phases.

## Secrets

Never commit a real `.env` file. Use `.env.example` as a template.
